## Quick Start with XSplit Premium

1. **Open XSplit Premium** - On the PC where the camera is plugged in.
2. **Load the scene** - Use the layout you already saved in XSplit Broadcaster.
3. **Check the sources** - Camera you own, screen you are actually using.
4. **Preview** - Look before anyone else sees the mix.
5. **Go live** - Only on the broadcast you host.
6. **Or stay light** - Use XSplit Gamecaster when the game window is enough.
7. **Stop** - Leave the scene file where you stored it.

## Understanding XSplit Premium Core Components

- **Scene** - The layout XSplit Premium is mixing.
- **Camera** - A device you own.
- **Screen** - A window on the PC you operate.
- **Broadcaster** - XSplit Broadcaster when the full scene matters.
- **Gamecaster** - XSplit Gamecaster when you only need the game window.
- **Preview** - The picture you check before the stream.
- **File** - The scene you stored for the next show.

## Closing Notes for XSplit Premium

Treat XSplit Premium as the mixer for a show you host, not as a recorder for every window on the PC. Open XSplit Broadcaster when the scene is the one you named. Keep sources few. Move test recordings out. Let old scenes stay quiet.

If you only need the game window, use XSplit Gamecaster and leave the rest off. If you show a teammate, show them the preview first. After that, XSplit Premium usually needs almost no explanation.
